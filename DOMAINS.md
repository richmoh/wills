## Recommendations

1. **Keep the Wasiyyah brand → register `wasiyyah.app`** (primary) and
   `wasiyyahwills.com` + `mywasiyyah.co.uk` (defensive/redirects, ~£20/yr total).
   The brand stays intact and the .app TLD suits a web product. Optionally send a
   quiet acquisition inquiry for the dormant `wasiyyah.com` / `wasiyyah.co.uk` —
   dormant registrations sometimes sell cheaply, but don't wait on it.
2. **If you'd rather own the .com/.co.uk pair outright → rebrand to
   `deenwills.com` + `deenwills.co.uk`** (or `amanahwills.com` + `.co.uk`). Getting
   both TLDs of a clean two-word name is rare; either name is instantly legible to
   the UK Muslim audience. A rebrand now costs one search-and-replace; in six
   months it costs users.
3. Whatever the choice, also grab **`muslimwill.co.uk`** if budget allows — it's a
   pure keyword domain worth owning for search, redirecting to the main site.

**One caution:** an established UK service operates as "My Wassiyah" (different
spelling) and wasiyya.com hosts a live product. Before committing to any name,
run a quick UK trade-mark search (gov.uk/search-for-trademark) for the chosen word.
